## 1. 已确认边界与当前落地事实

首期使用 **Uni-app + Vue 3 的一个小程序工程**，提供老人适老化极简模式和子女远程监护模式两种模式，共用后端身份、请求封装及必要基础组件。老人可查看本人健康、用药打卡、长按 2 秒 SOS 求助、适老帮助和服务履约进度；子女在当前有效亲情授权范围内查看老人资料、监视体征走势、维护用药计划、代办助老照护预约及接收关怀通知。

当前 `apps/elder-family/` 已实现 M01 至 M11 全模块前端交互原型，包含：
1. **统一认证与角色分流 (M01)**：统一登录 (`pages/auth/login.vue`)、双模式分流 (`pages/auth/role-select.vue`)、老人 6 位激活码免密绑定 (`pages/elder/activate.vue`)、子女自主注册 (`pages/family/register.vue`)、密码恢复与人工申诉 (`pages/auth/forgot-password.vue`)；
2. **老人档案与亲情关系 (M02)**：老人资料自维护 (`pages/elder/profile.vue`)、亲情绑定申请 (`pages/family/bind-apply.vue`)、子女监护首页与 5 种授权态拦截 (`pages/family/dashboard.vue`)、档案更正申请与 409 冲突模拟 (`pages/family/correction-apply.vue`)；
3. **健康体征与 SOS 应急求助 (M03/M05)**：长辈关怀首页与长按 2 秒 SOS 防误触及误触带痕取消 (`pages/elder/home.vue`)、子女端长辈健康走势与三级血压超标告警条 (`pages/family/health-trend.vue`)；
4. **日常用药管理 (M04)**：老人端今日药盒大字一键打卡与通俗标签 (`pages/elder/medication-box.vue`)、子女端不可变版本计划管理与应急刷新当日任务 (`pages/family/medication-plan.vue`)；
5. **助老预约与履约跟踪 (M06/M07)**：四大照护目录代预约 (`pages/family/service-booking.vue`)、助老服务履约全生命周期大字垂直时间轴 (`pages/family/order-timeline.vue`)；
6. **关怀通知消息 (M11)**：超时未服药关怀提醒与一键致电长辈闭环 (`pages/family/notifications.vue`)。

历史原型使用纯前端 Mock 状态；当前主要业务页面从真实 API 读取和提交。剩余缺口包括浏览器写入/异常分支、真机和全模块验收，不再将 Mock 切换器作为真实业务成功证据。

## 3. 会话、身份与请求边界

1. 手机号加密码登录，登录后从服务端获取当前可用身份与对象权限。兼任老人和子女身份时，两种模式的页面数据上下文分开；切换模式重新取当前权限，不自动复用另一个身份的数据。
2. `api/http` 统一处理服务地址、会话凭据、`/api/v1`、`traceId`、响应体和 HTTP/业务错误；业务 API 文件只声明具体请求。
3. 会创建业务事实、推进状态或触发副作用的请求（如打卡、预约、更正）使用 `Idempotency-Key`。同一次网络重试复用原键和同一规范化输入；一次新的真实 SOS 或新的业务操作使用新键。
4. 所有业务日期与截止以服务端按 `Asia/Shanghai` 判定的结果为准；前端负责清晰显示，不用本机时钟决定打卡或预约是否最终可接受。

## 4. 老人端关键交互

| 操作 | 必须保持的业务语义 | 已实现的页面交互状态 |
| :--- | :--- | :--- |
| **SOS 长按与防误触** | 必须连续按压满 2 秒才向后台发送求助；不足 2 秒松开自动回弹；老人若点击误触取消，必须二次确认并保留取消事实，后台生成电话回访工单。 | • 待命态：SVG 环形动态渐变进度条 + 触感振动；<br>• 求助中态：透明告知已调度网格员，无虚假承诺；<br>• 取消确认态：大字二次确认并保留带痕取消记录。 |
| **服药任务与本人确认** | 展示通俗标签（如【降压药】）；当日任务在提醒时段醒目提示；老人自主打卡点击后语音播放播报确认反馈。 | • 待服用、已按时打卡、过窗未确认三种明确状态卡片。 |
| **服务履约大字进度** | 使用 M06 权威工单流转记录；直观展示服务人员姓名、联系方式、预计上门时间与履约节点。 | • 待派单、已接单、上门服务中、服务已完成、已审核结案大字垂直时间轴。 |

## 5. 子女端关键边界

子女注册或登录不自动获得老人数据；经核验的亲情关系及其当前状态决定访问。亲情冻结、解绑、账号停用后，列表、详情、统计、文件和写入均须由服务端立即拒绝。子女可在有效授权范围内维护用药计划，但不得代替老人打卡或发起 SOS；仅原申请人可按当前预约状态发起允许的取消/中止流程。跨老人切换须清空上一对象的敏感页面状态并重新加载。
