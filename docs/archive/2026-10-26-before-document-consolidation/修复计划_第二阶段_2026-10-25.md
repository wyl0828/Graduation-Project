### P0 — 打通真实链路（必须先做，否则其余都演示不了）

#### P0-1 管理端登录与会话传输 `0.5 天`
- **改动**：`apps/admin-web/src/api/http.ts`、`src/router/index.ts`、新增 `src/views/auth/AdminLoginView.vue`、`src/layout/AdminLayout.vue`、`src/api/adminApi.ts`。
- **要点**：
  1. 删除 `|| 'demo-admin-token'`；无令牌一律跳 `/login`；
  2. 登录调用 `POST /api/v1/auth/login`（`clientType: "WEB"`）；推荐直接用 **Cookie + `X-CSRF-Token`**（后端已支持，登录返回 `csrfToken` 并下发 HttpOnly Cookie）；若想省事可暂用 Bearer（后端已放开）；
  3. 加 `router.beforeEach` 守卫 + 401 拦截 → 清会话 → 跳登录；
  4. 退出登录真正调用 `/auth/logout` 并清空状态。
- **验收**：未登录访问任意路由 → 跳登录；登录后 F5 仍保持；令牌过期后任意请求 → 跳登录；产物里搜不到 `demo-admin-token`。
- **验证**：`npm run build`；手工走一遍。

#### P0-2 管理端页面接真实 API `1 天`
- **改动**：`views/dashboard`、`views/audit`、`views/order/*`、`views/elder/*`、`views/family/*`、`views/health/*`、`views/medication/*`。
- **要点**：优先接 4 个与答辩强相关的：**看板、工单派单、工单结案审核、审计**；其余页面若本轮不接，必须在页面顶部显示"原型数据"标识，禁止把 Mock 数字当真实结果展示。
- **验收**：刷新后页面数据来自接口；断网时显示错误态而不是 Mock 数字。
- **依赖**：P0-1。

#### P0-3 小程序登录/激活/绑定/更正/预约接真实 API `1.5 天`
- **改动**：`pages/auth/login.vue`、`pages/elder/activate.vue`、`pages/auth/register.vue`、`pages/auth/forgot-password.vue`、`pages/family/bind-apply.vue`、`pages/family/correction-apply.vue`、`pages/family/service-booking.vue`、`pages/family/order-timeline.vue`、`api/elderApi.ts`、`api/http.ts`。
- **要点**：
  1. `get()` 支持 query 参数序列化，错误对象透传 `code`；
  2. 修复 5 处路径/形状不符（SOS active、vitals latest、告警列表取 `items`、仿真 stop/inject）；
  3. 登录存 token 并按 `activeRole` 分流；激活走"挑战 → 验证码 → consume"；
  4. 目标老人一律来自会话/`my-elders`，删掉硬编码 `elderId: 1`。
- **验收**：小程序里能真实登录、真实激活、真实发起预约并能在管理端看到。
- **依赖**：P0-1（后端无需改动）。

#### P0-4 失败不得显示成功 `0.5 天`
- **改动**：`pages/elder/home.vue`、`pages/elder/medication-box.vue`、`pages/family/health-trend.vue`、`views/health/EmergencyAlertView.vue`、`views/health/SimulationControlView.vue`、`views/order/WorkOrderExecutionView.vue`。
- **要点**：SOS 必须拿到 `sosId` 才进入"已受理"；打卡/体征/结案/仿真失败时回滚本地状态并给重试入口；离线态文案不得使用"已通知网格员"等真实语义。
- **验收**：断网后逐页操作，页面不得出现"已受理/已打卡/已结案"。
- **依赖**：P0-3。

#### P0-5 统一错误处理 `0.5 天`
- **改动**：两个 `api/http.ts`、各页面 catch。
- **要点**：401 → 清会话跳登录；403 → 提示无权限；409 → 提示冲突并刷新；5xx → 提示稍后重试并可复制 `traceId`；禁止空 `catch {}` 吞掉。
- **验收**：用无效令牌/越权/重复提交分别触发，页面有明确提示。

#### P0-6 工程门禁 `0.5 天`
- **改动**：`apps/elder-family` 的 16 处 type-check 错误（5 处 `get()` 多参 + 11 处原生 `<button type>`）；新增 `ops/windows/smoke-api-contract.ps1`。
- **要点**：脚本对登录、档案、工单、预约、告警、仿真 6 组接口断言"路径 + 状态码 + 响应形状"，用真实启动的 API 跑。
- **验收**：`npm run type-check` 零错误；冒烟脚本退出码 0。
