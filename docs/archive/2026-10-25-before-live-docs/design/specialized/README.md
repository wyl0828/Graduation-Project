## 使用规则

- 先以 SRS v1.0 判断业务边界，再以总体设计 v1.1 判断总体架构；跨模块共享实体、API 错误、锁序候选、时间、审计/通知和状态映射以集成基线 v1.1 为准；物理 DDL、完整端点和并发验证不由该基线代替。
- v0.1 专项正文中的共享候选若与集成基线冲突，以集成基线为准；模块详细字段、端点、错误处理和 AT 步骤须在 D2/D3 冻结点修订到位。
- 各专项中的测试均是待执行方案；没有真实运行证据的项目保持“未测”。
- 符合集成基线不等于可以直接编码；每个模块仍须满足 §5.2 开工门槛，尤其 M06 需先补完整专项。
