# 项目实施计划

本文件只保留当前推进顺序与完成门槛。较早状态盘点见[2026-10-27 历史快照](../validation/项目状态盘点_2026-10-27.md)；本轮工程与 ECS 证据见[2026-10-29 ECS 生产发布与线上验收记录](../validation/ECS生产发布与线上验收记录_2026-10-29.md)。专项实现证据按日期列在[验证索引](../validation/README.md)。

## 目标与当前基线

项目目标是交付可复现、可演示且权限与业务状态可信的社区居家养老系统。截至 2026-10-29，后续阶段 Task 2–5 的限定范围已完成，ECS 当前 release 已上线；工程测试、构建、线上状态及快照明细统一见本文件开头链接的当日验收记录。交付阶段仍未整体完成：生产快照尚未做恢复或回滚演练，设备、用户走查和性能验收仍开放。论文 Word 与写作按用户要求暂缓；不以局部工程完成推导全 AT 或全部生产验收通过。

| 5. 论文与答辩材料 | 只引用已验收的架构、截图和测试结果 | 按用户要求暂缓 Word 更新与论文写作；不在本轮启动。 |

## 当前优先任务

1. **完成剩余交付验收**：用隔离副本实测数据库/文件联合恢复、失败恢复与 RPO/RTO；执行真实 release 回滚演练；补做异机备份、微信开发者工具/Android/iOS、至少 5 名非开发者走查和固定规模性能压测。未测前保持开放。
2. **补齐 AT-11 通知边界**：核对接收角色、无收件人处理、发送/重试前当前授权复核和失败结果；SOS 通知失败不得回滚已受理业务。
3. **论文与答辩材料**：当前不启动 Word 更新或论文写作；待用户后续要求且相关工程证据确定后再处理。

各项完成结论以验证索引中的带日期记录为准；本计划只保留当前推进顺序和门槛，不重复历次测试数字。

没有短信服务时，手机号找回、子女注册与老人首次激活保持安全关闭；引入可信核验渠道后再规划启用及验收。
