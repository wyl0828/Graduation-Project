## 目标与当前基线

项目目标是交付可复现、可演示且权限与业务状态可信的社区居家养老系统。当前**未提交共享工作区**已在独立临时 MySQL 上完成 Flyway V1–V3.3、合成种子、六类账号登录、服药打卡、预约履约结案、SOS 处置与注销会话撤销。最新 HTTP/隔离断言 42 项通过；后端测试 137 项中 133 通过、4 项按环境跳过。管理端、H5 与微信小程序构建及管理端静态检查通过；浏览器核对四角色页面、一次档案写入/读回、看板空态与错误态。详情和限制分别见上述两份验证记录。以上不代表干净检出、部署环境、微信真机或 M01–M12 全项验收。
