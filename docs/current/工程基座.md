# 工程基座与本地运行

本文件保留当前操作入口。2026-10-25 的 D1 选型、干净检出和阶段验收原文见[整理前快照](../archive/2026-10-26-before-document-consolidation/工程基座.md)及[D1 验收记录](../validation/D1工程基座验收记录_2026-10-25.md)。

## 目录与启动

- `services/api/`：Spring Boot API、Flyway 迁移和后端测试。
- `apps/admin-web/`：Vue 管理端。
- `apps/elder-family/`：Uni-app 老人/子女端。
- `database/seed/`：仅含合成数据的首装种子。
- `ops/windows/`：开发环境检查、启动、种子加载和测试脚本。

在 Windows PowerShell 中依次运行 `ops/windows/check-dev-env.ps1`、`ops/windows/init-local.ps1`，按[根 README](../../README.md)配置本机 MySQL 和被忽略的 `.env.local`。使用 `ops/windows/start-api.ps1` 启动 API；仅在确认目标库为空且写入静默时运行 `ops/windows/load-demo-seed.ps1`。两个前端分别 `npm ci` 后按各自 README 启动或构建。

独立临时库联调运行 `ops/windows/tests/Test-SystemHttpTempDb.ps1`；脚本建立临时 MySQL、迁移、加载合成数据、执行后端测试和 HTTP 主链，随后清理实例。它不代表已使用演示库的安全重置，也不替代干净检出或真机验收。HTTP/Maven 结果见[系统隔离联调记录](../validation/系统隔离联调记录_2026-10-26.md)，近期前端与浏览器闭环见[演示闭环验收记录](../validation/演示闭环验收记录_2026-10-26.md)。
