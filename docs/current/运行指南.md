# 本地运行指南（Windows）

本指南使用本机 MySQL 和**合成演示数据**。需要 Java 17、Node.js、npm、MySQL 8 与 PowerShell；仓库使用 Maven Wrapper。先在仓库根目录运行：

```powershell
./ops/windows/check-dev-env.ps1
./ops/windows/init-local.ps1
```

`init-local.ps1` 只创建本地文件和被 Git 忽略的 `.env.local`，不会建库。按 `.env.example` 编辑 `.env.local`：`DB_HOST=127.0.0.1`、`DB_NAME=elderly_care_demo`、`DB_USERNAME=elderly_app`，填写本机独立的 `DB_PASSWORD` 和至少 32 字节的 `AUTH_RATE_LIMIT_HMAC_KEY`。只在本机 HTTP 开发时设 `AUTH_COOKIE_SECURE=false`；`PHONE_VERIFICATION_ENABLED=false` 保持不变。HMAC 值可在 PowerShell 用 `[Convert]::ToHexString([Security.Cryptography.RandomNumberGenerator]::GetBytes(32))` 生成，不要提交生成结果。

## 首次使用全新演示库

先以本机 MySQL 管理员执行下面 SQL，密码与 `.env.local` 的 `DB_PASSWORD` 一致。若目标库或账号已存在，停止此首装步骤，转用下一节；不要删除已有库以重新加载种子。

```sql
CREATE DATABASE `elderly_care_demo` CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE USER 'elderly_app'@'127.0.0.1' IDENTIFIED BY '<本机独立强密码>';
GRANT SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER, DROP, INDEX, REFERENCES
  ON `elderly_care_demo`.* TO 'elderly_app'@'127.0.0.1';
```

从仓库根目录运行 `./ops/windows/check-demo-db.ps1`。在**第一个终端**运行 `./ops/windows/start-api.ps1`，等待 Flyway 迁移和 `http://127.0.0.1:8080/actuator/health` 返回健康状态，然后按 Ctrl+C 停止 API。确认没有其他应用写入该库，运行 `./ops/windows/load-demo-seed.ps1`；它只允许空白的 `elderly_care_demo` 首次导入。随后重新运行 `./ops/windows/start-api.ps1` 并保持终端开启。

## 已有演示库

保留现有数据库和 `.env.local`。运行 `./ops/windows/check-demo-db.ps1 -RequireMigration` 后，直接执行 `./ops/windows/start-api.ps1`；Flyway 会验证并应用尚未执行的迁移。**不要重复运行** `load-demo-seed.ps1`，它不是重置脚本。若已有库的数据或迁移与当前源码不匹配，先备份并诊断，不要用删库处理。

## 启动两个前端

API 保持运行；另开两个 PowerShell 终端，分别执行：

```powershell
cd apps/admin-web
npm ci
npm run dev
```

```powershell
cd apps/elder-family
npm ci
npm run dev:h5
```

管理端默认 `http://127.0.0.1:5173/`，老人/子女 H5 默认 `http://127.0.0.1:5174/`。两端开发服务器把 `/api` 代理到 `http://127.0.0.1:8080`；如 API 端口不同，启动前在各终端设置 `VITE_API_PROXY_TARGET`。合成账号见[接口契约 §5.1](./接口契约_M01_M02.md)。管理端使用社区管理员或网格员账号，H5 使用老人或子女账号。

微信小程序先运行 `npm run build:mp-weixin`，再在微信开发者工具导入 `apps/elder-family/dist/build/mp-weixin/`。构建前须配置设备可访问的 HTTPS `VITE_API_BASE_URL`（包含 `/api/v1`）；设备的 `127.0.0.1` 不是开发电脑。微信平台域名与真机能力尚需另行验收。

## 不使用已有演示库的整链验证

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File ops/windows/tests/Test-SystemHttpTempDb.ps1
```

脚本自行建立并清理独立临时 MySQL，执行迁移、合成种子、后端全套测试和跨角色 HTTP 主链；不会重置现有演示库。HTTP/Maven 结果见[系统隔离联调记录](../validation/系统隔离联调记录_2026-10-26.md)，管理端与小程序页面验收见[演示闭环验收记录](../validation/演示闭环验收记录_2026-10-26.md)。需要浏览器连接临时 API 时使用 `-HoldSeconds 300`，并在该随机端口释放前完成浏览器检查；未运行中的旧端口不能复用。没有短信服务时，注册、首次激活和找回入口仍安全关闭。
