# 老人与子女端代码架构

`apps/elder-family/` 是 Uni-app + Vue 3 工程，同一客户端按当前会话角色进入老人或子女页面。历史纯前端 Mock 原型、当时的页面状态和切换器设计保存在[整理前快照](../archive/2026-10-26-before-document-consolidation/小程序代码架构.md)。当前页面以服务端响应作为业务结果。

| 位置 | 当前职责 |
| --- | --- |
| `src/pages/auth/` | 角色选择、登录与安全关闭的找回入口。 |
| `src/pages/elder/` | 老人首页、本人资料、当日药盒和 SOS。首次激活在无可信手机号核验时关闭。 |
| `src/pages/family/` | 授权老人切换、体征、用药、服务预约与进度、通知、亲情和更正申请。注册在无可信手机号核验时关闭。 |
| `src/api/`、`src/state/` | HTTP 客户端、真实接口封装与会话/当前老人状态。 |
| `src/components/` | 适老组件和共享页面组件；历史 `MockSwitcher.vue` 不作为真实业务状态来源。 |

子女页面须按当前 `ACTIVE` 亲情关系获取老人数据；切换老人时清除上一对象敏感状态并重取。老人打卡和 SOS 只有服务端接受后才显示成功。交互目标详见各[原型与交互设计](./README.md)；最终权限和失败语义以[需求与范围](./需求与范围.md)及服务端契约为准。

构建命令和设备 API 地址见[工程 README](../../apps/elder-family/README.md)。[2026-10-26 隔离联调记录](../validation/系统隔离联调记录_2026-10-26.md)只证明当前未提交工作区的 H5 主要页面和真实 HTTP 主链；微信开发者工具与真机需单独验收。
