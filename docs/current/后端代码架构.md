# 后端代码架构

后端是 Spring Boot 单体，入口位于 `services/api/`。实际包结构如下；目标事务规则见[跨模块设计](./跨模块设计.md)，旧版本的候选流程与测试清单见[整理前快照](../archive/2026-10-26-before-document-consolidation/后端代码架构.md)。

| 包 | 职责 |
| --- | --- |
| `common/` | 统一响应、异常、会话安全、权限、幂等和追踪等共享能力。 |
| `infrastructure/` | 数据库、存储和运行基础设施。 |
| `coordination/` | 预约确认与工单等需要同事务协调的跨模块流程。 |
| `modules/auth`、`elder` | 账号会话、角色与社区管理员工账号管理 API，档案、亲情与更正。 |
| `modules/health`、`emergency`、`simulation` | 体征、告警、SOS 与受控仿真。 |
| `modules/medication`、`notification` | 用药计划、日期任务、打卡和通知。 |
| `modules/reservation`、`order` | 服务目录、预约、调度、工单执行与审核；`CARE_WORKER` 执行授权限制为本人当前社区的非终态分配工单。 |
| `modules/dashboard`、`audit` | 看板读模型与操作审计。 |

每个业务模块以自己的 Controller、Service、Mapper 和领域数据为边界。请求时以服务端当前会话、角色和对象关系授权；跨模块状态由拥有该状态的模块写入。预约确认建单、SOS 建单等流程由协调服务保证同事务一致性。接口与字段以实际控制器和[接口契约](./接口契约_M01_M02.md)核对，不能把旧设计路由表当成已实现接口清单。

数据库迁移位于 `services/api/src/main/resources/db/migration/`，当前工作区包含 V1、V2、V3、V3.1–V3.3。测试位于 `services/api/src/test/`。可复现的隔离库运行入口是 `ops/windows/tests/Test-SystemHttpTempDb.ps1`；[批次 1 验收记录](../validation/批次1-数据入口与授权边界验收记录_2026-10-27.md)说明员工角色管理、护工工单授权及最终 Maven/HTTP/浏览器结果；此前主链见[系统隔离联调记录](../validation/系统隔离联调记录_2026-10-26.md)。代码结构说明不等于 M01–M12 全项验收。
