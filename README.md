## D1 工程骨架

仓库包含后端工程入口、健康检查与 Flyway 迁移入口，以及本地配置和 Windows 初始化脚本。两个前端目前只有目录说明，尚未生成依赖锁文件或运行构建；当前也没有业务模块。

```powershell
./ops/windows/check-dev-env.ps1
./ops/windows/init-local.ps1
# 编辑 .env.local，配置本机隔离演示数据库 elderly_care_demo
./ops/windows/start-api.ps1
```

`.env.local` 和 `.local-data/` 已加入忽略规则。脚本不会创建或清空数据库；D1 尚未验收通过。

## 推荐阅读与下一步

1. 阅读本页，确认权威文件及状态。
2. 阅读 SRS v1.0、冻结决定记录和校验清单。
3. 阅读集成设计基线 v1.1 和需求追踪矩阵，作为 E-01—E-07 的共享规则入口。
4. 执行 D1 工程基座初始化与验收；通过后再建立共享支撑和业务模块，不把目录骨架等同于功能完成。
5. D1 通过后建立共享支撑并补齐 M06 完整工单专项；M08/M09 详细设计在各自模块开工前完成，再冻结对应 DDL/API。
6. 每个模块满足集成基线开工门槛后再实现；AT/A 仅按真实运行记录更新状态。

集成基线已统一文档层面的共享口径；锁序仍待逐事务核对和并发验证，模块完整 API、物理 DDL、部署手册和运行证据仍待阶段交付。需求冻结、总体设计确认或专项初稿均不代表代码完成或验收通过。
