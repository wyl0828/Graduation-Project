# 第 7 章 结束语

## 7.1 工作总结

随着我国“9073”养老格局的深化以及老龄化程度的不断加深，构建高效、可信、无障碍的数字化居家养老服务基础设施具有深远的社会价值与现实意义。本文以国家无障碍环境建设法规和工信部适老化通用规范为指导，针对现有智慧养老系统“重静态数据展示、轻线下履约闭环、适老化流于形式、权限边界模糊”等行业共性痛点，设计并实现了《基于 Spring Boot 与适老化设计的社区居家养老服务系统》。

本论文的主要工作与成果总结如下：
1. **构建了四方协同的闭环业务架构**：打破了传统平台单纯面向老年人或管理员的单一视角，建立了贯通“老年人（受助端）、监护子女（家属端）、网格员/护工（履约端）、社区管理员（调度端）”的四方协同联动机制。实现了从健康体征异常预警或突发 SOS 求助，到社区网格化派单调度、护工线下照护履约、现场照片存证、最终审核结案归档的完整业务闭环。
2. **形式化设计了基于有限状态机（FSM）与乐观锁的工单调度机制**：针对服务链条长、状态繁多的问题，形式化定义了包含 8 种离散状态的有限状态机与角色转移约束矩阵，杜绝了非法状态跳跃；利用数据库行级乐观锁版本控制（`version`），在单体分层架构下以极低成本解决了多人并发派单与高并发抢单接单的竞态冲突。
3. **基于认知负荷理论系统落实了适老化交互设计**：深刻契合老年人的感知与记忆衰退规律，立足于削减外在认知负荷，在 Uni-app 移动端落地了大字号（$\ge 18\text{pt}$）、大触控热区（$\ge 48\times 48\text{dp}$）、高对比度及单向任务流设计，辅以语音播报与一键防误触倒计时，切实破除了老年人的“数字鸿沟”。
4. **实现了细粒度社区属地隔离与动态授权机制**：建立了基于物理社区编码的行级多租户隔离体系，严格约束社区管理员与网格员的管辖物理边界；对上门护工推行“本人分配工单”最小必要受权，对监护子女实施亲情解绑即时失权，筑牢了老年人健康隐私的安全防线。
5. **开展了详尽的工程实证与质量测试**：基于 Spring Boot 3、MyBatis-Plus 与 Flyway 构建了高可靠的单体工程底座，设计了 170 余项自动化单元测试、权限边界渗透测试与高并发压力测试，实测证明系统在 50 并发负载下平均响应时延控制在 $130\text{ms}$ 以内，吞吐量超过 $360\text{ req/s}$，错误率为 0，具备工业级健壮性。

## 7.2 系统不足与未来展望

受限于毕业设计研发周期、硬件实验环境以及基层医疗资源对接条件，本系统仍存在以下不足，有待在后续演进中深入探索：
1. **真实物联网（IoT）低功耗传感器直连与认证机制**：当前系统体征数据主要依托人工录入与服务端轻量仿真引擎（带有 `SIMULATION` 标记）。未来工作可引入低功耗蓝牙（BLE 5.0）与 NB-IoT 窄带物联网技术，接入智能手环、智能床垫与毫米波跌倒雷达，并在网关层建立设备双向 TLS 认证与硬件级设备身份指纹体系，提升体征采集的自动化与可信度。
2. **医养深度结合与院前急救绿色通道打通**：当前突发 SOS 告警主要联动社区网格员与监护子女。未来可进一步探索与属地社区卫生服务中心或“120”院前急救指挥系统的 API 接口联通，在发生危急事件时支持一键导出老人既往慢性病史与用药禁忌，为急救医生提供第一手参考档案。
3. **基于长者行为图谱的个性化关怀智能推荐**：随着社区运行数据的长效沉淀，未来可尝试在合规脱敏的前提下，基于机器学习对老人的日常作息与体征波动规律进行画像建模，自适应预测潜在慢病并发症风险，由“事后响应式调度”向“事前预防式主动关怀”升级演进。
